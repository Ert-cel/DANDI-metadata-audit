# Core audit workflow

DANDI ID
→ DANDI API
→ NWB structured metadata
→ CatalystNeuro curated dataset metadata
→ associated publication Methods
→ optional confirmed CatalystNeuro project page
→ source evidence table
→ audit template
→ usage summary

## Why this design

The audit is an evidence/provenance exercise. A value matters together with where it came from and whether it was structured or inferred from prose. The core engine therefore avoids broad discovery and records narrative values as candidates requiring review.
